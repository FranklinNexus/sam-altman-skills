# Evaluation

Use these prompts to test whether this skill produces useful answers.

## Prompts

- "We have ten possible directions. Which should we focus on?"
- "Our AI product has many demos but no retention."
- "Should we do the hard ambitious version or the easy version that can ship faster?"

## Quality Bar

A strong answer should:

- Diagnose the real bottleneck.
- Ask only necessary clarifying questions.
- Separate evidence from narrative.
- Give an action with a time window.
- State what would change the recommendation.
- Avoid roleplay, imitation, long quotations, and private source leakage.

A weak answer:

- Sounds motivational but does not change the next action.
- Gives the same advice to every problem.
- Ignores missing evidence.
- Pretends to provide legal, financial, employment, visa, or investment advice.
